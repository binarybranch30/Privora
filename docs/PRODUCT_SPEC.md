# Product spec

A presenter first transfers the synthetic source-code document to the approved external analyzer. The presenter then updates the synthetic provider policy and repeats the same call. The review-required decision references the changed policy and the receipt count stays at one. A public transfer demonstrates that the destination can continue serving permitted requests.

The dashboard shows connected services, review state, policy versions, changed passages, the organization rule, and the transfer audit. The MCP tool accepts only a document ID and destination ID. The optional review flow records an administrator's version-specific verification and evidence.

Demo terms and documents are fictional. A real-policy observation can be triggered through the local administrative endpoint. The demo requires no paid services.
