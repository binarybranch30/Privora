# Privora MCP

A single-organization dashboard for hackathon presenters and developers to inspect how provider policy changes affect individual MCP transfers. Its primary evidence is the provider clause, the gateway decision, and the downstream receipt count.

The product runs locally using synthetic documents and provider terms. Provider monitoring can be configured for a public policy URL. The gateway must keep enforcing the same rules when the dashboard is closed. Private document bodies belong on the trusted subprocess path.

The brief sets a dark operational interface, plain policy language, and accessible feedback. The dashboard uses a restrained graphite palette and reserves accent colors for transfer and review states.
